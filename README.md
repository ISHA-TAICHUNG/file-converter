# 📋 ISHA 台中職訓中心 — 檔案轉檔工具

**線上網址**：https://isha-taichung.github.io/file-converter/

給 **ISHA-TAICHUNG 內部承辦同仁** 使用的檔案轉檔工具。把每期考試要處理的 PDF/XLSX 資料用網頁一鍵轉成查詢系統可讀的格式，取代原本要開 Google 文件、Python 腳本的流程。

---

## 🔒 為什麼要做這個工具

原本的流程有這些痛點：
- 成績單簽收總表 PDF 要用 Google 文件開啟才能存 TXT，多次轉檔繁瑣
- XLSX 報檢資料含 **電話、MAIL、地址、生日等個資**，手動篩欄位容易出錯、也容易忘記過濾
- Python 腳本要熟悉終端機才能跑

這個工具全部在**瀏覽器本地**處理：
- ✅ 檔案**絕對不上傳任何伺服器**
- ✅ 關閉分頁資料即消失
- ✅ 自動過濾個資（不讓承辦同仁不小心把個資 push 到雲端）
- ✅ 任何裝置只要有瀏覽器都能用，不用裝任何東西
- ✅ 開過一次可離線使用

---

## 📘 兩大功能

### 1️⃣ 成績單簽收總表 PDF → TXT（給管理職類查詢系統用）

**使用時機**：每期收到新的成績單簽收總表 PDF 時（忠明、龍井可分別轉檔）。

**操作步驟**：

1. 打開 https://isha-taichung.github.io/file-converter/
2. 看到「📄 成績單簽收總表 PDF → TXT」卡片
3. 把 PDF 拖進虛線框 **或** 點擊虛線框選檔（可同時選多個 PDF）
4. 按「🔄 開始轉檔並下載 TXT」
5. 瀏覽器自動下載 `.txt` 檔到 Downloads 資料夾
6. 把 TXT 上傳到 **Google Drive 管理職類測驗資料夾** (`查詢資料庫/管理職類測驗/`)
   - 檔名需含「成績單簽收」；本工具輸出檔名會自動符合
   - 忠明、龍井可放多個成績單簽收總表 TXT
7. 管理職類查詢系統會直接讀取資料夾內所有檔名含「成績單簽收」的 TXT

**輸出範例**：
```
職業安全衛生教育訓練結訓測驗
成績單簽收總表
中華民國工業安全衛生協會附設台中職業訓練中心 115 年度 第 06 梯次 第 01 場次 本教室共 30 人
測驗日期：2026/6/15 測驗時間：8:20~10:00 測驗教室：(01) 第9教室
座號 身分證編號 姓名 期別 准考證號碼 測驗職類 應試者簽名
0101 A22XXXXX06 李芳禹 114OHN5 115M00906010101 15040勞工健康服務護理人員及
2-2 勞工健康服務相關人員
...
```

**技術細節**：
- 用 PDF.js 4.0.379 抽取文字
- 依 y 座標自動分行、同行按 x 座標排序（避免欄位錯亂）
- 保留中英文、全形半形原樣

---

### 2️⃣ 報檢資料 XLSX → CSV（給即測即評查詢系統用）

**使用時機**：每期收到新的即測即評報檢 xlsx（術科 + 學科兩份）時。

**支援兩種檔案**：

| 檔名特徵 | 自動辨識為 | 產出 | 欄位數 |
|---|---|---|---|
| 檔名含「學科報檢資料」 | 學科報檢 | `學科報檢資料.csv` | 7 |
| 其他（含 SKT1 分頁）| 術科報檢 | `報檢資料.csv` | 8 |

**操作步驟**：

1. 打開 https://isha-taichung.github.io/file-converter/
2. 看到「📊 報檢資料 XLSX → CSV」卡片
3. 把**兩份 xlsx 同時**拖進虛線框（或點擊逐個選）
4. 按「🔄 開始轉檔並下載 CSV」
5. 瀏覽器自動下載兩份 CSV（`報檢資料.csv`、`學科報檢資料.csv`）
6. 把兩份 CSV 上傳到 **Google Drive 即測即評資料夾** (`技術職類（即測即評）/`)
   - 覆蓋舊的同名檔
7. 去 Google Sheet 按「📚 題庫管理 → 🗑️ 清除題庫快取」
8. 即測即評查詢系統下次呼叫時會讀到新資料

**輸出範例（報檢資料.csv — 以下欄位/值皆為虛構示例）**：
```csv
職類代碼,級別,免試別,准考證號,身分證號,姓名,術科測試日期,術科測試時間
PNO,EGR,DSTNG,AENO,IDNO,NAME,OPEXDT,OPEXTIME
06100,4,,G0610000C000000,A123456789,王小明,1150505,08:30-12:00
...
```

**保留的欄位（8 欄，術科報檢）**：
- PNO 職類代碼、EGR 級別、DSTNG 免試別（B=免術科）
- AENO 准考證號、IDNO 身分證號、NAME 姓名
- OPEXDT 術科日期、OPEXTIME 術科時間

**保留的欄位（7 欄，學科報檢）**：
- 准考證號、學科測試編號、場地、試場、場次、測試日期、測試時間

**自動過濾（不輸出）**：
- 電話（公、宅、行動）
- MAIL
- 地址
- 生日
- 身障類別
- 其他所有未明確列入「保留清單」的欄位

**技術細節**：
- 用 SheetJS 0.18.5 處理 XLSX
- 輸出 UTF-8 BOM 編碼，Excel 雙擊可直接打開不亂碼
- CSV 欄位如含逗號/引號自動跳脫

## 🔐 隱私與安全說明

### 為什麼可以確定「沒有上傳」

1. **原始碼完全公開**（你現在看的這個 repo），任何人可以稽核
2. 只引用兩支純前端 JS 函式庫（PDF.js、SheetJS），都是透過 CDN 只讀
3. 沒有任何 `fetch('https://...')`、`XMLHttpRequest` 向外送檔案的程式碼
4. 瀏覽器開發者工具 Network 分頁可以即時看到，轉檔過程**不會有任何上傳請求**

### 個資過濾的技術保證

XLSX 轉 CSV 的程式碼裡有個明確的 **白名單**（`ALLOWED_REG_FIELDS` / `ALLOWED_WRITTEN_FIELDS_ZH`），只有白名單內的欄位才會被寫進 CSV。其他欄位（電話、地址等）在原始碼層級就**不會讀進來**，而不是讀了再過濾。

承辦同仁不會因為「漏打勾」「按錯鍵」而不小心外洩個資。

### 離線使用

第一次使用後，瀏覽器會 cache 住 CDN 的 JS，之後沒網路也能用（只要不清快取或切換瀏覽器）。承辦電腦若有網路限制，第一次能連外網即可。

└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│  2. 拖 2 個 xlsx → 下載 2 份 CSV        │
│     (報檢資料.csv、學科報檢資料.csv)    │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│  3. 拖成績單簽收總表 PDF → 下載 TXT    │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐

整個流程約 **2 分鐘**。

## 🚨 常見問題

### Q1: 按「開始轉檔」顯示「SheetJS 尚未載入完成」
**原因**：網路慢或 CDN 被擋。
**解法**：
1. 等 5-10 秒再按一次（程式會自動重試 8 秒）
2. 強制重整：`⌘⇧R`（Mac）/ `Ctrl+Shift+R`（Windows）
3. 檢查網路或公司防火牆是否阻擋 cdnjs.cloudflare.com

### Q2: TXT 格式跟以前用 Google 文件轉的不一樣
**正常**：新工具用 PDF.js 按 y/x 座標重建閱讀順序，最終欄位排列與原 PDF 相符。查詢系統的後端邏輯不依賴特定空白或換行，只要每筆含「座號、姓名、准考證號、測驗職類」字串即可。

### Q3: 想確認 CSV 有沒有個資洩漏
**做法**：用 Excel 或 Google 試算表打開 CSV，看欄位名稱是否只有：
- 術科：`職類代碼 級別 免試別 准考證號 身分證號 姓名 術科測試日期 術科測試時間`（8 欄）
- 學科：`准考證號 學科測試編號 場地 試場 場次 測試日期 測試時間`（7 欄）

若出現「電話」「MAIL」「地址」等欄位 = **異常**，請回報。

### Q4: 這個網頁會不會被關掉？
不會。此工具是靜態 HTML/JS，由 GitHub Pages 託管，只要 GitHub 還在就一直能用。未來想搬到其他地方也只是把 3 個檔案（index.html、style.css、convert.js）放到任何 web server 即可。

### Q5: 可以在手機用嗎？
可以，介面響應式支援手機。但手機下載檔案會進到手機的 Downloads，要自行搬到電腦再上傳 Drive 比較麻煩，**建議在電腦上用**。

## 🧑‍💻 開發者資訊

### 檔案結構
```
file-converter/
├── index.html    # 主頁面 + 兩個功能區塊的 UI
├── style.css     # 所有樣式（含 RWD）
├── convert.js    # PDF.js / SheetJS 邏輯
├── README.md     # 本說明
└── .gitignore
```

### 修改與部署
```bash
git clone https://github.com/ISHA-TAICHUNG/file-converter.git
cd file-converter
# 修改檔案後
git add . && git commit -m "..." && git push
# GitHub Pages 會自動 1-2 分鐘內部署
```

### 相依套件（皆透過 CDN 載入）
- [PDF.js](https://mozilla.github.io/pdf.js/) 4.0.379（Mozilla 官方 PDF 函式庫）
- [SheetJS](https://sheetjs.com/) 0.18.5（社群版）

### 本地測試
```bash
cd file-converter
python3 -m http.server 8000
# 打開 http://localhost:8000
```
